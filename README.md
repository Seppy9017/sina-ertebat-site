# سایت سینا ارتباط

سایت معرفی شرکت + کاتالوگ محصولات (دوربین مداربسته، یو‌پی‌اس، تجهیزات روشنایی)
+ ورود/ثبت‌نام کاربران + پنل مدیریت، ساخته‌شده با **React + Vite**.

## پیش‌نیاز

- [Node.js](https://nodejs.org) نسخه 18 یا بالاتر (شامل npm)

## نصب و اجرا

```bash
npm install     # فقط بار اول لازم است
npm run dev
```

بعد از اجرای `npm run dev`، آدرسی شبیه `http://localhost:5173` در ترمینال
نمایش داده می‌شود؛ آن را در مرورگر باز کنید.

## دستورات دیگر

```bash
npm run build     # ساخت نسخه‌ی نهایی برای انتشار (خروجی در پوشه dist/)
npm run preview   # پیش‌نمایش نسخه‌ی build‌شده
```

## ورود / ثبت‌نام و پنل‌ها

دکمه‌ی «ورود» در هدر سایت (یا آدرس `/#/panel`) کاربر را به یک صفحه‌ی
واحد ورود/ثبت‌نام می‌برد:

- **ثبت‌نام:** هر بازدیدکننده‌ی عادی می‌تواند با نام کاربری و رمز عبور
  دلخواه خودش حساب بسازد.
- **ورود:**
  - اگر نام کاربری/رمز عبور دقیقاً همان چیزی باشد که در جدول زیر آمده،
    وارد **پنل مدیریت** می‌شود.
  - اگر یک نام کاربری/رمز عبور ثبت‌شده (توسط خود شخص در بخش ثبت‌نام) وارد
    شود، وارد **پنل کاربری عادی** خودش می‌شود.
  - در غیر این صورت پیام «نام کاربری یا رمز عبور اشتباه است» نمایش داده
    می‌شود.

### پنل مدیریت شامل چیست؟

- **محصولات:** افزودن محصول جدید (دسته‌بندی، نام، مدل، مشخصات فنی، و
  **قیمت به تومان** — اختیاری)، ویرایش قیمت هر محصول مستقیماً از داخل
  جدول، حذف محصول، و بازگردانی به لیست پیش‌فرض. اگر قیمتی برای محصولی وارد
  نشود، در فروشگاه به‌جای قیمت «استعلام قیمت» نمایش داده می‌شود.
- **پیام‌های تماس:** هر پیامی که از فرم «تماس با ما» ارسال شود، اینجا
  قابل مشاهده است (همراه با نام کاربری فرستنده، اگر وارد حساب بوده باشد).

### پنل کاربری عادی شامل چیست؟

- اطلاعات حساب (نام کاربری، شماره تماس در صورت وارد کردن هنگام ثبت‌نام)
- درخواست‌های استعلام قیمتی که همان کاربر از فرم «تماس با ما» ارسال کرده

### ⚠️ نکته‌ی مهم امنیتی

این پروژه **یک سایت استاتیک بدون بک‌اند** است — بررسی نام کاربری/رمز عبور،
ذخیره‌ی حساب‌های کاربری، محصولات و پیام‌ها همگی **در همان مرورگر کاربر**
(با `localStorage`/`sessionStorage`) انجام می‌شود، نه روی یک سرور. یعنی:

- هرکسی که ابزار توسعه‌دهنده‌ی مرورگر را باز کند یا فایل build‌شده در
  `dist/` را بررسی کند، می‌تواند رمز عبور پنل مدیریت را ببیند.
- حساب‌های کاربری، محصولات و پیام‌ها فقط روی همان مرورگر/دستگاهی ذخیره
  می‌شوند که در آن ثبت‌نام یا ثبت شده‌اند — بین دستگاه‌های مختلف مشترک
  نیستند (کسی که از گوشی‌اش ثبت‌نام کند نمی‌تواند از لپ‌تاپ دیگری با همان
  حساب وارد شود).
- رمزهای عبور به‌صورت متن ساده در `localStorage` ذخیره می‌شوند، نه
  هش‌شده — این برای یک دمو یا سایت داخلی قابل قبول است، اما برای اطلاعات
  واقعی حساس مناسب نیست.

این سیستم برای **جلوگیری از دسترسی تصادفی به بخش‌های مدیریتی و شخصی‌سازی
ساده برای کاربران عادی** مناسب است، اما جایگزین یک سیستم احراز هویت واقعی
(با بک‌اند، دیتابیس مرکزی و رمزهای هش‌شده) نیست. اگر بخواهید چنین بک‌اندی
هم اضافه کنم، فقط بگویید.

## ساختار پروژه

```
sina-ertebat/
├── package.json
├── vite.config.js
├── index.html               نقطه ورود Vite
├── public/
│   └── favicon.png          آیکون تب مرورگر (لوگوی «S»)
└── src/
    ├── main.jsx              رندر اولیه React
    ├── App.jsx                کامپوننت‌های سایت + مسیریابی به /panel
    ├── icons.jsx              آیکون‌های SVG
    ├── data.js                اطلاعات شرکت، متن درباره ما، محصولات پیش‌فرض
    ├── adminConfig.js         نام کاربری/رمز عبور پنل مدیریت
    ├── index.css              تمام استایل‌ها
    ├── assets/
    │   ├── logo-mark.png      لوگوی نشان (آیکون S نارنجی) — هدر و فوتر
    │   └── logo-full.png      لوگوی کامل (وردمارک SINA ERTEBAT) — هیرو
    └── admin/
        ├── AuthPage.jsx       صفحه‌ی واحد ورود/ثبت‌نام
        ├── AdminPanel.jsx     پنل مدیریت محصولات، قیمت‌ها و پیام‌ها
        ├── UserPanel.jsx      پنل کاربری عادی
        └── storage.js         ذخیره‌سازی محلی (localStorage): محصولات، پیام‌ها، حساب‌های کاربری
```
